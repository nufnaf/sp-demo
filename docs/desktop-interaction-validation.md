# 桌面交互入口与洞察同步验收

## 改动

- 演示桌面移除“对话记录”入口，输入框 Logo、语音文字记录和任务入口不会打开聊天面板。任务卡打开对应成果或浏览器；输入框与语音交互保留。
- AI 交互区置于业务窗口、启动台、工作台菜单、Dock 菜单和通知之上。启动台不再声明为阻断其他入口的模态界面。
- JD 发布建议与洞察报告由同一组件生成通知和桌面列表。关闭发布通知后，建议仍在 widget 中可操作；发布中禁用重复操作，成功后移除待发布建议。
- 报告卡片显示结论摘要；已存在的报告可以从文件正文补取摘要，无需重新生成。关闭或阅读通知不会删除桌面洞察。

## 自动检查

类型检查与修改文件的 lint 通过。32 项相关回归覆盖通知和 widget 同步、关闭与刷新恢复、发布中状态、报告摘要、输入交互层级，以及 Electron 服务和运行目录管理。

全仓 lint 仍有技能样例中的既有错误；旧的工作台／飞书组件源码匹配测试也有与当前实现不符的既有断言。本次未把这些历史失败记为通过。
