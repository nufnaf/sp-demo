# HTML 产物生成规范

`lib/html-artifact-prompt.ts` 提供共用的内容与视觉设计规范，由生成任务按读者、目标和素材选择版式，不使用固定报告模板。用户指定的交付格式、品牌和风格优先。

- 普通工具会话：资源加载时追加任务规范，保留项目发现的 `APPEND_SYSTEM.md`；Jarvis 委派的任务也使用这条路径。
- 子代理：有工具或加载资源的子代理在创建与恢复时使用相同规范，保留角色与父任务上下文。
- 后台洞察：在分析请求中嵌入静态版本，保留无洞察时的 `<NO_INSIGHT/>` 协议和现有 HTML 安全过滤。
- Chat only 和纯对话子代理保留精确系统提示词行为。Jarvis 本身继续负责交流与委派。

规范覆盖任务适配、信息层级、主题视觉、数据图形、可访问性、响应式、打印与真实交互。任务产物按需保存文件；洞察只返回无脚本的自包含页面。提示词不是 HTML 清洗器，也不保证模型每次都达到设计标准。

新会话或重新加载资源后生效，已生成文件不会被自动重写。确定性演示报告仍由各自的 HTML 渲染器负责。

## 人工效果验收

使用相同模型生成以下任务，在约 390px、768px 和 1440px 宽度预览实际 HTML，并检查打印模式：

| 输入 | 应体现的差异 |
| --- | --- |
| 一条客户回款阻塞洞察，附时间与证据 | 紧凑结论、证据链与少量建议，无假操作按钮 |
| 三个供应商的选型比较 | 可读的对比矩阵、权衡与推荐依据 |
| 六周产品上线计划 | 阶段、依赖与责任安排，不伪造完成率 |
| 长篇研究报告，附来源 | 编辑式阅读布局、页内目录与来源注释 |
| 有品牌色的活动介绍 | 贴合品牌的主视觉与内容节奏，不强制指标卡 |
| 预算计算工具 | 可用的输入与结果反馈，键盘可操作 |

共同检查：首屏表达任务结果；没有虚构数据或素材；中文长标题和长链接不溢出；图表单位与文字结论完整；没有失效的资源或控件。自动化测试验证规范注入、项目提示保留、子代理恢复去重及 Chat only 边界；视觉质量仍需实际生成后验收。
