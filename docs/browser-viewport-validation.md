# 浏览器任务完成时的尺寸跳变修复

## 原因与调整

2026-09-07 用户录屏第 22–23 秒中，浏览器窗口保持原尺寸，但招聘网页整体缩小。此前任务页面以 1280 × 800 创建，Agent 执行时拒绝容器尺寸同步；任务结束后移除独立状态行，触发 ResizeObserver，此时尺寸同步恢复，导致网页突然按容器尺寸重新排版。

现在任务页面在发出前台打开事件后，先接收容器尺寸，再交给执行器导航和读取网页。执行期间继续锁定尺寸。没有可见界面的调用最多等待 1.5 秒后使用默认尺寸；超时收口与尺寸更新使用同一页面操作队列，避免迟到请求干扰执行。

任务提示和停止按钮移入固定高度的工具栏，完成后隐藏提示不会改变网页区域的宽高。完成、失败和停止都不主动重设网页尺寸；接管后用户仍可正常操作和调整窗口。
