# 安装版走查后续修复

基于最新 `origin/dev`（`8f2c262`）在 `codex/ui-audit-followup` 独立 worktree 实现。范围为用户确认的三处样式问题与查询结果入口；通知浮层保持原有行为。

## 修改

- 报告：AI 洞察内嵌报告和独立报告窗口共用阅读区域，根据输入框实际位置与大小避让；窗口拖动、缩放、聚焦和保留草稿时重新测量。只改变阅读视口，不改报告正文、会议动作或输出文件。
- 招聘统计卡：数字和标签从顶部统一排列，长标签换行不再改变数字基线。
- 候选人档案：“面试评价”“流程记录”统一为 16px / 600 / 24px，增加段前间距和列表行距。
- 查询任务：已完成招聘查询优先打开摘要，显示岗位、查询问题、时间、面试结束/评价未齐人数、待补评价名单和浏览器查询结论；保留候选人、已有报告、任务网页入口。候选人入口打开对应岗位的缺评价筛选。Dock 任务入口与首页共用路由，并限定当前工作台。
- 查询快照：在 Browser Use 成功、当前岗位快照核验通过后，与招聘进展原子保存；按 sessionId 区分历史查询。后续同步不会覆盖旧结果。没有历史快照的旧任务标明展示最近同步进展。运行、失败、取消状态保持原任务入口；读取失败提供重试。
