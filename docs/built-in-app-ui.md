# Agent OS 内置应用界面规范

适用于人才招聘、投资管理和销售 CRM。共用入口为 `WorkspaceAppIcon.tsx`，样式为 `WorkspaceApps.css`，应用根节点通过 `os-workspace` 加入规范。业务流程和数据模型仍由各应用维护。

## 视觉层级

- 延续 Agent OS 的浅色材质和系统字体，内容区使用中性背景与白色表面；侧栏使用轻磨砂材质。
- 招聘与 CRM 使用绿色强调色，投资使用紫色；强调色只承担品牌、选中态、状态和主要操作。
- 常规侧栏宽 208px，中等窗口 176px，窄窗口 64px。三个应用的导航和品牌标识对齐。
- 页面标题 24px / 650，正文和导航 13px，按钮 12px，辅助信息 11px。CSS 使用 rem，按当前根字号 14px 换算，以便跟随文字缩放。
- 面板圆角 12px，控件圆角 7–8px，细边框与轻阴影；避免大面积品牌色背景和重复的装饰性标题。
- 搜索框与分段筛选共用尺寸；统计区为等宽四栏，窄屏两栏。表格保持阅读密度，空间不足时横向滚动。

## 交互与适配

- 按下即提供反馈，不为静态按钮添加弹跳；保留键盘焦点环。
- 图标导航必须有可访问名称和悬停提示。
- 使用容器查询匹配实际应用窗口，而非仅依赖浏览器宽度。
- 主内容底部预留滚动空间，使最后一个操作能滚动至 Jarvis 浮层之上。
- 响应 reduced-motion、reduced-transparency 和 prefers-contrast。
- 当前跟随 Agent OS 的浅色外观；不独立根据设备偏好切换单个应用的表面材质。

## 样式维护

共用样式使用应用范围内的明确优先级，不依赖各 CSS chunk 的加载顺序。桌面 `font: inherit` 不得重置应用控件字号。应用特有布局留在各自样式表，新增共用控件应复用本规范。
