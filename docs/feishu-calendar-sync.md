# 飞书演示日程接入

本轮需求覆盖此前的本地演示日程要求：招聘工作台的日程卡片、团队日程窗口以及飞书资料窗口中的“会议”读取同一个专用飞书日历。没有 local/feishu 模式开关，也不再补入固定的本地演示日程。

## 演示行为

- 初始显示北京时间今天起 7 天的真实日程；团队日程可切换前后 7 天或回到今天，桌面卡片同步使用同一个范围。
- 首次打开、返回应用、网络恢复、手动刷新，以及页面可见时每 30 秒读取日程。多个窗口共享读取结果和请求。
- 从招聘洞察或管线安排对齐会议，后台向配置的日历创建真实日程，收到成功响应后才记录已安排状态并刷新两处展示。
- 标题、时间、地点和会议说明来自飞书返回结果；重复日程以实例展示，已取消日程不出现在列表。全天日程保留日期，不按本机时区平移。
- 会议默认安排在北京时间明天 14:00–14:30；名单与议程来自本轮招聘洞察，名单写入说明，不调用参与人接口，不发送邀请，不自动生成会议室或视频会议。
- 网络或权限失败会显示错误。刷新失败而保留上次结果时会明确标注，不能把旧数据称为刚同步成功。
- 创建前在演示目录保存请求标识和原始时间。重复点击共享同一操作，丢失响应后重试沿用飞书 `idempotency_key`。已保存日程 ID 后，再次点击读取该远端日程，不重复创建；远端已取消或不可访问时报告失败。
- 完全退出仍清理本轮本地演示目录，但不调用飞书删除接口。下次启动是新一轮演示，可新增会议；上一轮日程保留。演示前可在飞书中手动清理需要移除的历史日程。

## 配置新应用

本机工作目录配置为 `.env.feishu-demo.json`，被 Git 忽略。先复制下面结构到文件，再只在本机编辑器填写真实值。不要把 Secret 或 token 粘贴到对话、命令行或日志。

```json
{
  "appId": "专用应用 App ID",
  "appSecret": "专用应用 App Secret",
  "folderToken": "演示文档文件夹 token",
  "documentIds": ["演示文档 docx token"],
  "calendarId": "专用共享日历的完整 calendar_id"
}
```

不是填写临时 `tenant_access_token`。后台用 App ID / App Secret 获取并按有效期更新 token。开发服务可通过 `SYNTROPIC_FEISHU_CONFIG` 指向指定的本机文件；修改文件后后续请求读取新配置。安装包沿用受控演示包配置方式，需重新打包才能使用新凭据。构建缺少 `calendarId` 时失败，不能交付一个仅能读文档的包作为完整日程演示。

App ID 标识应用，不代表电脑上登录的飞书用户。接口权限和具体资料的共享权限需要同时满足。

1. 在新应用开通并发布文档只读权限：`drive:drive:readonly`、`docx:document:readonly`；将文件夹及目标文档共享给该应用。保留已有 documentIds 白名单校验。
2. 在新应用开通并发布日程读取和创建权限：`calendar:calendar.event:read`、`calendar:calendar.event:create`。如使用旧的综合授权 `calendar:calendar`，它也涵盖这两类接口；不要为了读取日程申请删除权限。
3. 准备专用共享日历。推荐由应用通过开放平台 API 调试台“创建共享日历”，再通过“创建访问控制”给演示账号授予阅读或管理权限；初始化接口所需权限按调试台提示单独配置。也可使用已存在且该应用具备读写权限的共享日历。
4. 把返回的完整 `calendar_id` 填入配置。不要填日历名称、浏览器地址、个人 user ID，也不要填 `primary`（它跟随当前身份，可能指向机器人的主日历）。
5. 在电脑飞书中登录演示账号，找到并订阅该共享日历，勾选显示。只在管理员后台开通 API 权限，不会自动让电脑飞书显示应用的日历。
6. 在共享日历准备与设计稿对应的基础日程，文档文件夹放入对应真实资料。应用会显示这些远端内容，不再自动生成两条日程占位数据。文档替换也需同步更新 folderToken / documentIds。

## 联调验收

1. 打开电脑飞书，确认订阅日历名称和基础日程；应用中打开团队日程及飞书资料，核对标题、日期、时间和正文来源。
2. 完成本轮招聘演示后，从洞察点击安排会议。应成功显示新增会议，两个应用内入口内容一致。
3. 切到电脑飞书，核对同一日程的标题、北京时间、名单说明和议程。应用返回的官方 app_link 可用于打开原日程。
4. 重复点击或刷新后重试，应保持同一日程 ID；网络失败不能显示创建成功。
5. 在飞书修改日程标题或时间，回到应用刷新，确认两处展示更新；取消日程后从列表消失。
6. 完全退出应用，在飞书确认日程仍在；新一轮演示前按需要手动清理旧日程。

## 官方接口

- [创建日程](https://open.feishu.cn/document/server-docs/calendar-v4/calendar-event/create)：应用或用户身份、幂等参数和通知选项。
- [查询日程视图](https://open.feishu.cn/document/server-docs/calendar-v4/calendar-event/instance_view)：查询区间小于 40 天，返回重复日程实例。
- [获取日程](https://open.feishu.cn/document/server-docs/calendar-v4/calendar-event/get)：按保存的日程 ID 获取当前状态。
- [创建共享日历](https://open.feishu.cn/document/server-docs/calendar-v4/calendar/create)、[创建访问控制](https://open.feishu.cn/document/server-docs/calendar-v4/calendar-acl/create)。
