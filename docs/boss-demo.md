# BOSS 直聘演示预设

Electron 演示每次启动时，在本轮独立的 `application/app-installations.json` 中预装 `boss-zhipin`。应用市场的“打开”和“已安装”列表、launcher 图标继续读取同一个安装接口；普通 Web 安装记录不变。

Dock 与飞书一样默认固定 BOSS 直聘：首次启动和已有 Dock 配置都会补齐这个入口，关闭应用窗口后图标仍保留，已有图标不会重复添加。普通 Web 的 Dock 偏好不变。

人才招聘默认将 BOSS 直聘接入招聘工作台，账号显示“星流科技 · 招聘团队”。断开与重新连接沿用当前工作台的本地连接记录，刷新保留，完整重启恢复预设。演示模式下打开 BOSS 使用本地展示窗口，不安装 CLI、不扫码、不请求 BOSS 网站。

发布流程保留内部招聘系统的真实网页填写、提交和最终核验。仅在本轮岗位核验通过后，`saveRecruitingProgress` 为同一岗位附加 `bossPublication` 模拟回执，包含 `mode: demo`、发布状态和原岗位发布时间。岗位列表、发布通知、桌面建议以及 BOSS 窗口读取同一份结果；失败、取消、核验失败不会产生成功回执。重复发布和后续查询不会重复创建岗位或改变模拟发布时间。

页面明确标注模拟结果。这项变更不把已有候选人改记为 BOSS 来源，不执行真实 BOSS 发布。完全退出后岗位和模拟回执随本轮数据清理，下次仍从已安装、已连接但尚未发布岗位的状态开始。

验收：应用市场“打开 BOSS 直聘” → launcher 搜索并打开 → 招聘应用显示已连接 → 断开、刷新、重新连接 → 发布成功后核对两处岗位 → 刷新保留 → 新一轮恢复预设。自动检查覆盖预设恢复、核验失败、重复发布、后续查询和完成文案。
