# JD 固定演示结果

招聘演示工作台收到明确的 JD 生成请求后，直接运行本地任务，经过 1.5 秒准备状态保存固定 HTML。任务派发、正文准备和完成回复均不调用模型，也不实时读取飞书。飞书应用保留；发布由程序直接交给既有 Pi 浏览器 Agent。

设计来源：[Figma JD 弹窗 523:2143](https://www.figma.com/design/kZRCbPpo7it0jcJLIgmxXp?node-id=523-2143)。完整保留公司介绍、职责、要求、加分项、待遇、招聘流程和右侧招聘信息。公司名称（包括原稿的 Syntrropic 拼写）、来源卡片、页尾和窗口招聘标签均使用星流科技。右侧品牌图标复用项目已有的 `public/icons/company-careers-logo.svg`，不使用 Syntropic 的 S 标识。

固定岗位为高级 AI Agent 研发工程师，Agent Platform，北京 / 上海，6 人，全职，3–8 年，混合办公。桌面招聘目标、日程、快捷提示、待发布岗位说明和发布表单默认值保持一致。其他岗位的历史种子数据不改写。

## JD 打开后的渐进展示

新生成的 JD 在完整窗口首次打开时播放约 18 秒的渐进展示。
标题与右侧招聘信息先出现，正文按章节分批追加文字，并在章节之间短暂停顿。
视口在底部时跟随内容增长，用户向上滚动后停止跟随；窗口退到后台时暂停，回到前台后继续。
正文呈现完毕后再等待 1.4 秒出现发布建议，播放期间隐藏对应的完成通知和已有发布建议。

动画只用于预览，保存的 HTML 始终完整、无脚本，发布读取的正文不受动画影响。
桌面使用新生成任务的 session 身份记录待播放成果，同名文件重新生成也会播放。
关窗或切换到源代码后重新打开直接显示全文，刷新后的历史成果也直接显示全文。
产物库缩略图与侧栏预览不播放动画，系统偏好减少动态效果时直接显示全文，打印会先补全内容。
普通 HTML 预览不启用这套 JD 展示逻辑。

验证命令：`node --test scripts/jd-streaming.test.mjs`。
该检查在 Chromium 的真实沙箱 iframe 中运行，覆盖展示时长、全文与标题完整性、后台暂停、滚动、窄屏、减少动态效果和打印。
桌面窗口的首次打开、关闭重开、刷新、产物库和重复生成另通过实际页面操作验收。

## 当前演示边界

- `SYNTROPIC_PRESENTATION_ROOT` 下的招聘及其他演示工作台不启动普通模型任务。未知输入返回固定的操作提示；不会回退到聊天模型、通用 Agent 或模型生成 JD。
- 招聘工作台支持生成 JD、发布岗位、查询招聘进展、停止任务。其他演示工作台仅展示预置资料；独立 Web 工作目录继续保留原有 Agent 能力。
- `lib/presentation-actions.ts` 识别明确动作，忽略网址中的 `draft`、对已完成生成的描述，以及否定指令。发布和生成是不同动作。
- `lib/recruiting-jd-fixture.ts`、`lib/recruiting-jd-demo-renderer.ts` 和 `public/design/jd/result.css` 负责完整的固定 HTML。约 1.5 秒准备后原子保存，取消不覆盖成果；SDK SessionManager 只用于任务历史和零模型用量记录。
- `lib/presentation-tasks.ts` 直接调用现有 Pi 浏览器 Agent。发布文件引用、目标地址和完整正文由程序准备；浏览器 Agent 是唯一调用模型的执行环节，负责真实填表、提交、核对。只读业务接口用于桌面展示和核验，不用于替代网页发布。
- 旧的模型 JD 合同、专用任务 profile、生成工具和 renderer 已删除。演示会话不加载普通 Agent 工具、技能或扩展；prompt、steer、follow-up 均进入固定流程。
- 发布结果未核实、网页失败或取消都不能记为完成。相同 JD 已发布时返回现有结果，不再次提交；通知根据已保存岗位消除过期发布建议。
- 输入框执行中显示“停止当前任务”，同时中止所属本地任务和浏览器操作。已提交的网页请求仍需核对其保存结果。
- 文件继续为 `ai-agent-engineer-jd.html`，公司为星流科技，产品为 Syntropic。报告、招聘进展与团队日程保持同一岗位数据来源。
- `scripts/package-desktop.mjs` 在签名前修复 agent-browser 可执行权限并实际运行版本命令，避免开发环境与安装包的权限差异。
