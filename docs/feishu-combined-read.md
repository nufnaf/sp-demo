# 飞书查找与读取合并（2026-09-09）

> 连接方式已更新：当前 App 通过启动前置页连接个人飞书并自动准备资源，参见 [当前配置步骤](feishu-demo-setup.md)。下文的专用应用凭据和固定资源配置为历史记录；日历与文档业务边界仍保留。

## 变化与边界

招聘 JD 后台现在只暴露 `feishu_demo_find_read` 和 `save_recruiting_jd`：模型按完整标题请求资料，程序列出授权文件夹、核对文档白名单、匹配唯一标题并读取正文，一次返回来源和正文，再由模型生成本轮 JD。

正常单页列表、令牌有效时，资料读取由原来的三次飞书请求（列表、再次列表核对、正文）减少为两次（列表、正文），同时省去列表返回后模型生成按 ID 读取指令的一次往返。首次令牌获取、分页和令牌失效重试另计；没有声称所有情况永远只发两次 HTTP 请求。

只接受完整标题完全匹配；空标题、无匹配、跨分页的多个同名文档均不会读取正文。正文请求仍由飞书检查当时的实际权限，列表返回后撤销权限会失败。复用的只是本次调用中已验证的列表结果，没有跨请求缓存文档正文或取消授权核对。原 `documents()`、`read(id)`、旧工具及资料窗口继续保留。

没有改用户可见输入话术、JD 长度与模板、主 Agent 模型、浏览器 Agent、发布方式、应用凭据或退出恢复范围。读取真实资料，生成真实正文，不以 mock 替代。

## 官方支持方式

飞书官方提供[自建应用获取 tenant_access_token](https://open.feishu.cn/document/server-docs/authentication-management/access-token/tenant_access_token_internal)接口，支持以 App ID / App Secret 获取应用令牌。官方[频控策略](https://open.feishu.cn/document/server-docs/api-call-guide/frequency-control)说明超频会返回限流响应，通常为 HTTP 429，并提供恢复等待时间。

这些说明支持使用授权 OpenAPI 的技术路径，不构成账号绝对不会受限的保证，也不表示官方特别认可本项目的安装包凭据分发方式。专用只读应用、限定资料及受控安装包的既定范围不变；本次仅减少调用步骤，不新增权限或更改账号。
