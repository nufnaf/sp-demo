# Syntropic Demo

Syntropic 是一个纯前端 Agent OS / 招聘工作台交互原型。候选人、日历、数据源和 AI 执行结果均为模拟数据。

## 启动

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

打开 <http://127.0.0.1:8000/>。

## 演示路径

首次打开时，Syntropic 会通过对话了解用户职业和工作目标。选择“人力资源 / 招聘”后，可以选择 Moka、北森和飞书进行演示数据导入，最后生成招聘工作台。已有工作区不会重复触发首次引导。

Dock 不会预置第三方应用。新手引导中选择的数据源会在生成工作台时自动安装并显示到 Dock；其他应用可从应用市场安装或卸载，Dock 会同步更新。

工作台创建后可按照页面引导体验以下主线：

1. 查看招聘目标与关键偏航。
2. 检查洞察依据和推进建议。
3. 查看需要人工确认的外部动作。
4. 通过全局 AI 输入继续任务。

右上角“演示数据”可查看模拟数据源、体验断连状态或重置整个演示。页面状态默认保存在浏览器中。

## 桌面组件

可以在全局 AI 中直接创建和修改桌面组件，例如：

- `生成一张候选人流失风险卡片，放到工作台。`
- `生成一张产品发布风险组件。`
- 从组件菜单选择“用 Syntropic 修改”，然后输入 `只看 Agent 工程师。`

对话生成组件以及招聘/产品工作台自带的默认组件都支持查看来源、编辑、用 Syntropic 修改、复制和移除。默认组件的改名与说明会按工作台保存，也可以随时恢复默认配置；移除后六秒内可撤销。

任务中心里的每个具体任务对话也可以生成桌面组件。点击对话顶部“生成组件”，或在任务输入框中输入“生成一张只看阻塞项的组件”；组件会记录任务来源与上下文，同一任务再次生成时会更新原组件。
